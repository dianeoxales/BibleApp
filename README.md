# BibleApp
A web application featuring a frontend and backend built with Node.js and RESTful APIs, implementing robust client-server communication and data persistence.

A full-stack web application that allows users to:
- Get random Bible verses
- Search verses by reference
- Save favourite verses
- Delete saved favourites

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- External API: bible-api.com

## How to Run
```bash
npm install
node server.js
